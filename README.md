# SupabaseCrudLab

ASP.NET Core MVC + Entity Framework Core + PostgreSQL (Supabase) CRUD application for Lab 11.

## Before running

1. Open the project in Visual Studio 2022/2026.
2. Restore NuGet packages.
3. Create a Supabase project.
4. Get the Session Pooler connection details. Use port 5432.
5. Right-click the project > Manage User Secrets.
6. Put your real connection string in secrets.json:

{
  "ConnectionStrings": {
    "Supabase": "Host=YOUR_HOST;Port=5432;Database=postgres;Username=YOUR_USER;Password=YOUR_PASSWORD;SSL Mode=Require;Trust Server Certificate=true"
  }
}

Do not put the password in appsettings.json or GitHub.

## Migration

Open the terminal in the folder containing SupabaseCrudLab.csproj and run:

dotnet tool install --global dotnet-ef
dotnet ef migrations add InitialCreate
dotnet ef database update

Then run the application and open Products.

## CRUD test

Create: Notebook, 250, 20
Read: confirm Notebook appears
Update: change price to 275
Delete: delete Notebook
Persistence: create again, stop and restart the app, then confirm it remains.

# ProductHub MVC

A product management web application built with **ASP.NET Core MVC, Entity Framework Core, and Supabase PostgreSQL**. This project demonstrates database connectivity, model validation, migrations, and complete CRUD functionality in a .NET web application.

## Overview

ProductHub MVC provides a web interface for managing product records stored in a PostgreSQL database hosted on Supabase.

It was developed as a practical lab project to demonstrate how an ASP.NET Core MVC application interacts with a relational database using Entity Framework Core.

## Features

- Create new product records
- View a list of products and individual product details
- Update existing product information
- Delete product records
- Validate product names, prices, and stock quantities
- Manage database schema through Entity Framework Core migrations
- Store database credentials securely with .NET User Secrets
- Persist product data in Supabase PostgreSQL

## Technology Stack

- **Language:** C#
- **Framework:** ASP.NET Core MVC
- **Database ORM:** Entity Framework Core
- **Database:** PostgreSQL via Supabase
- **Database Provider:** Npgsql.EntityFrameworkCore.PostgreSQL
- **Development Environment:** Visual Studio
- **Package Management:** NuGet
- **Configuration Security:** .NET User Secrets

## Product Data Model

The application manages a `Product` entity with the following fields:

| Field | Type | Purpose |
|---|---|---|
| Id | int | Primary key |
| Name | string | Product name; required, maximum 100 characters |
| Price | decimal | Product price; range 0.01–1,000,000 |
| StockQuantity | int | Available stock; range 0–1,000,000 |

## Setup and Installation

### Prerequisites

- Visual Studio with the ASP.NET and web development workload
- A compatible .NET SDK (10 or 8, according to your course requirements)
- A Supabase account and PostgreSQL project
- Git and a GitHub account

### 1. Clone the repository

```bash
git clone https://github.com/mdfarooq17/AspNetCore-Supabase-CRUD-Management-System.git
cd AspNetCore-Supabase-CRUD-Management-Syste
```

Open the project or solution in Visual Studio.

### 2. Install the required packages

Install these NuGet packages using versions compatible with your chosen .NET version:

- `Microsoft.EntityFrameworkCore.Design`
- `Microsoft.EntityFrameworkCore.Tools`
- `Npgsql.EntityFrameworkCore.PostgreSQL`

Install the Entity Framework command-line tool if required:

```bash
dotnet tool install --global dotnet-ef
```

### 3. Configure Supabase

Create a Supabase project and obtain the PostgreSQL connection details. Configure the connection string under the `ConnectionStrings:Supabase` key using .NET User Secrets.

Do not commit your database password or connection string to GitHub.

### 4. Create the database schema

Run these commands from the directory containing the `.csproj` file:

```bash
dotnet ef migrations add InitialCreate
dotnet ef database update
```

Verify that the `Products` table exists in the Supabase Table Editor.

### 5. Build and run

```bash
dotnet restore
dotnet build
dotnet run
```

Alternatively, run the application through Visual Studio.

### 6. Test CRUD operations

1. Create a product named Notebook with price 250 and stock quantity 20.
2. Verify that the product appears in the product list.
3. Edit the price to 275 and save.
4. Delete the product and confirm its removal.
5. Restart the application and verify that saved records persist.

## Security

- Keep database credentials outside source control.
- Use .NET User Secrets for local development.
- Never publish passwords, private connection strings, or `secrets.json`.
- Use appropriately restricted database credentials for real deployments.

## Learning Objectives

This project demonstrates:

- ASP.NET Core MVC architecture
- C# model creation and data annotations
- Entity Framework Core and `DbContext`
- PostgreSQL connectivity using Npgsql
- Database migrations
- CRUD controller and view scaffolding
- Secure local configuration
- Database persistence and application testing

## Project Scope

This is a learning project focused on product CRUD operations and database integration. It does not currently claim authentication, role-based access control, payment processing, or production deployment.
